# Проблемы и риски

Планируется подключение в систему дополнительных систем страховых компаний. В связи с этим возникают следующие риски.

1. Увеличится время на обработку REST запроса сервисом **ins-product-aggregator**. Сервис **ins-product-aggregator**, во время REST запроса к нему, будет опрашивать дополнительные 5 систем.

2. Больше вероятность сбоя при запросе в серсисе **ins-product-aggregator**. В случае ошибочного запроса в любую систему страховых компаний, запрос в сервис ins-product-aggregator завершится с ошибкой. С ростом числа таких систем, вероятность ошибки повышается.

3. Возможны ошибки по таймауту в запросах к ins-product-aggregator. Если системы страховых компаний будут долго отвечать на запросы, то суммарный запрос к ним может завершиться по таймауту. 

4. Ошибки от систем страховых компаний при превышении лимитов запросов. В случае роста числа запросов и данных сторонние системы могут отдавать ошибки по запросам о превышении лимита или увеличивать время ожидания ответа на запрос.

5. Повторные запросы одних и тех же данных. Сервис ins-product-aggregator часто запрашивет одни и те же данные. Это нерационально и увеличивает объем передаваемых данных. При геораспределении это увеличит время обработки.

6. Рост нагрузки на ins-product-aggregator при одновременных запросах от других сервисов.

7. Большой объем данных об оформленных страховках. В кейсе, когда ins-comp-settlement раз в сутки осуществляет запрос в core-app по REST API для получения всех оформленных за день страховок, есть риск получить ошибки из-за объема получаемых данных. Это может быть:
   
   - больше вероятность ошибки при передачи данных по сети;
   
   - дольше ожидание формирования ответа, что может приветси к ошибкам по таймауту;
   
   - в случае ошибки, возможно не будет сформирован отчет.
